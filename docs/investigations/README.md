- [测量摘要](evidence/phase-0-measurements.json)、[全部三次结果](evidence/phase-0-benchmarks.json)、[来源版本证据](evidence/phase-0-sources.json)：Phase 0 小型历史快照，非生产类型或接口。

注明日期、提交、命令、版本、重复次数、口径和局限。大型数据库/日志不放这里，只保留紧凑汇总；事实、观察、假设、未测分开。
